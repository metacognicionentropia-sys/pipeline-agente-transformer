Pipeline de Inferencia: Agente + Transformer

Integración del flujo agentico externo y la secuencia interna de un Transformer moderno

Secuencia Transformer
Vista Integrada
Sampling Interactivo
1. UsuarioEntrada
Mensaje del usuario. Puede incluir texto, imágenes o herramientas implícitas.
↓
2. Filtros de entrada (paralelos)Seguridad
Moderación, detección de jailbreaks, clasificación de intención, rate limiting, validación de esquema. Se ejecutan en paralelo.
↓
3. Construcción de contextoPrompt
Historial + system prompt + RAG (documentos recuperados) + memoria de largo plazo. Aquí se forma el prompt final que verá el modelo.
↓
4. Router / PlanificadorDecisión
Decide: respuesta directa (sin tools) o loop agentico (necesita herramientas, búsqueda, código, etc.).
↓
5. Loop agentico (opcional)N veces
LLM ↔ Herramientas / RAG. El modelo decide qué llamar, observa el resultado y repite hasta tener suficiente información o alcanzar el límite de iteraciones.
↓
6. Filtros de salida + verificadorCalidad
Moderación de la respuesta, chequeo de alucinaciones, verificación de hechos cuando es posible, control de calidad.
↓
7. Postprocesado + formateoSalida
Markdown, citas, cards, imágenes, estructuración final.
↓
8. RespuestaUsuario
Se entrega al usuario.

Secuencia fundamental de inferencia de un Transformer moderno (según tus capturas):

1. TextoInput
Cadena de caracteres de entrada (prompt + contexto).
↓
2. TokensIDs
Tokenización (BPE / SentencePiece). Ejemplo: "Tokyo" → [2435] o subwords.
↓
3. Embeddings + Positional EncodingVectores
Cada token ID se convierte en un vector denso. Se suma (o concatena) la información de posición para que el modelo entienda el orden.
↓
4. Transformer Layers (×N)Bloques
Cada capa contiene:
• Multi-Head Self-Attention (Q, K, V → atención causal)
• Feed-Forward Network (SwiGLU / GELU)
• Residual connections + LayerNorm / RMSNorm
Se repite N veces (32, 80, etc.).
↓
5. Hidden StatesRepresentación
Representación final del último token (o de todos, según el caso).
↓
6. LogitsVocab
Proyección lineal al tamaño del vocabulario (scores sin normalizar).
↓
7. Softmax → ProbabilidadesDist
Convierte logits en una distribución de probabilidad sobre el vocabulario.
↓
8. Temperatura + Top-K / Top-PFiltrado
Temperatura controla la aleatoriedad. Top-K y Top-P recortan la cola de la distribución.
↓
9. SamplingSelección
Se muestrea un token según la distribución filtrada (o greedy si temperatura=0).
↓
10. Token generadoOutput
Se decodifica a texto y se añade al contexto para el siguiente paso autoregresivo.

El flujo agentico envuelve al Transformer. Cada vez que el agente necesita "pensar", llama internamente a la secuencia de inferencia del modelo.

Capa externa: Orquestación del Agente Agente
Usuario → Filtros entrada → Construcción de contexto (historial + system + RAG + memoria) → Router → [Loop agentico: LLM ↔ tools] → Filtros salida → Postprocesado → Respuesta
↓ (cuando el Router decide llamar al modelo)
Capa interna: Inferencia del Transformer Modelo
Texto → Tokens → Embeddings + Posicional → Transformer Layers (Multi-Head Attention + FFN) × N → Hidden States → Logits → Softmax → Temperatura/Top-K/Top-P → Sampling → Nuevo Token
↓ (token(s) generados vuelven al agente)
Ciclo completo
El agente puede invocar al modelo varias veces (una por paso del loop). Cada invocación ejecuta la secuencia completa del Transformer sobre el contexto actualizado (incluyendo resultados de herramientas).

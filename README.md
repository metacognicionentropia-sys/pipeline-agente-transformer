# Pipeline de Inferencia: Agente + Transformer

Visualización educativa e interactiva que integra dos vistas de cómo responde un sistema de IA:

- **Flujo Agente:** el recorrido externo (usuario, filtros, contexto, router, loop con herramientas, respuesta).
- **Secuencia Transformer:** la generación interna de texto (tokens, embeddings, atención, logits, softmax, sampling).
- **Vista Integrada:** ambos flujos juntos.
- **Sampling Interactivo:** controles para ver el efecto de temperatura, Top-K y Top-P.

> Nota: es un esquema conceptual con fines didácticos. Los valores y probabilidades son simulados; no provienen de un modelo real.

**Ver en línea:** https://metacognicionentropia-sys.github.io/pipeline-agente-transformer/

Es una sola página HTML, sin dependencias: también se puede abrir `index.html` directamente en el navegador.
